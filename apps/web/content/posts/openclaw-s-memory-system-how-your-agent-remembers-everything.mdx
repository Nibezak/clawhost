## Memory in OpenClaw: How Your Agent Learns and Remembers

Unlike chatbots that reset with each conversation, OpenClaw agents remember, learn, and adapt.

### Three Tiers of Memory

**Conversation Memory** - Immediate context
**Session Memory** - Facts and patterns from recent work
**Long-term Memory** - Permanently stored knowledge

### How It Works

The agent notices patterns, recognizes what works, avoids mistakes, and develops specialized expertise over time.

### Privacy and Control

Since OpenClaw runs on your infrastructure, your memory data stays on your servers with no third-party access.
