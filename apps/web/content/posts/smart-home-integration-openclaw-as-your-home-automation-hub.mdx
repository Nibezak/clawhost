## Smart Home Integration: OpenClaw as Your Home Automation Hub

Your home is full of smart devices. But they don't talk to each other.

OpenClaw changes that. One agent to control everything.

## The Smart Home Problem

Today's smart homes are fragmented:

```
Lights: Controlled via Philips Hue app
Thermostat: Controlled via Nest app
Door lock: Controlled via Yale app
Speakers: Controlled via Alexa app
Camera: Controlled via Ring app
Sprinkler: Controlled via Rainmachine app

Result: 6 different apps, 6 different interfaces, no automation
```

Each device is smart in isolation. Your home isn't intelligent.

## OpenClaw Solves This

One agent controls everything:

```
You: "Turn off all lights, lock the door, and set thermostat to 68°F"

Agent:
1. Turns off lights (Philips Hue integration)
2. Locks door (Yale integration)
3. Sets thermostat (Nest integration)
4. All in parallel
5. Confirms: "Home locked and secured"
```

## Setup

### Step 1: Connect Integrations

Tell OpenClaw what devices you have:

```javascript
{
  "integrations": {
    "philips-hue": {
      "api_key": "your-hue-key",
      "bridge_ip": "192.168.1.100"
    },
    "nest": {
      "api_key": "your-nest-key",
      "refresh_token": "..."
    },
    "yale": {
      "api_key": "your-yale-key",
      "lock_serial": "LOCK-001"
    },
    "sonos": {
      "api_key": "your-sonos-key"
    }
  }
}
```

Each integration takes ~5 minutes to set up.

### Step 2: Define Automation Rules

```bash
npm run automation:create

# Define automation:
Name: "Bedtime routine"
Trigger: When I say "Goodnight"

Actions:
1. Turn off all lights
2. Lock all doors
3. Set thermostat to 62°F
4. Close garage door
5. Play sleep sounds on speakers
6. Set alarm for 7 AM

Result: One command, everything automated
```

### Step 3: Use It


## Scenes vs Automations

### Scene

```
One-time action triggered by you:
"Turn on movie mode" → runs immediately
"Set relaxation scene" → runs immediately
```

### Automation

```
Recurring action triggered by condition:
"When I leave home" → runs automatically
"At 6 PM every day" → runs automatically
"When temperature drops below 65°F" → runs automatically
```

Both are powerful. Use both.

## Advanced: Conditional Logic

Create intelligent automations:

```javascript
Automation: "Adaptive lighting"

If (time between sunset and 11 PM) {
  Turn on lights to 50% brightness
  Set color temperature to warm
}

If (time after 11 PM) {
  Turn on lights to 20% brightness
  Set color temperature to very warm
  Enable night mode
}

If (motion detected && lights already on) {
  Keep lights at current level
}

If (motion not detected for 15 min) {
  Turn lights off
}
```

Result: Lights adapt to time of day, motion, and current state.

## Troubleshooting

### Device not responding

```
Problem: "Philips Hue is not responding"
Solution:
- Restart device
- Check bridge is online
- Re-authenticate in integration settings
```

### Automation not running

```
Problem: "Bedtime routine didn't run at 10 PM"
Solution:
- Check OpenClaw is running
- Check agent has permission to control device
- Check automation is enabled
- Check time zone setting
```

### Device is on wrong network

```
Problem: "Can't reach Yale lock"
Solution:
- Move lock to same WiFi network
- Use bridge device if available
- Check firewall allows local traffic
```
