## The Gateway: OpenClaw's Central Coordination Hub

Every complex system needs a nervous system. In OpenClaw, that's the Gateway.

### Core Responsibilities

- **Routes messages** between components
- **Manages state** across the agent's lifetime
- **Coordinates tools** and skills
- **Handles sessions** and conversations
- **Manages memory** and persistence
- **Triggers actions** and workflows

### How It Works

When you message an agent, the Gateway:
1. Authenticates you
2. Finds your conversation history
3. Enriches message with context
4. Sends to agent brain
5. Executes decisions (runs tools)
6. Sends results back to agent
7. Formulates response
8. Updates memory and history

This happens in seconds for simple tasks.
