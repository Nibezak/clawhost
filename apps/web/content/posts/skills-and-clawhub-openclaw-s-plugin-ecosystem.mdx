## Skills and ClawHub: Extending OpenClaw's Capabilities

Skills are reusable capabilities that extend what agents can do. ClawHub is the marketplace where developers publish and discover skills.

### What Are Skills?

Superpowers for agents:
- Email management
- Browser automation
- Code execution
- File operations
- Calendar management
- Messaging integrations
- Database access

### The Ecosystem Effect

OpenClaw's power multiplies with each new skill. Developers build and publish skills to ClawHub, which the community installs and combines creatively.

### Building Your Own

If you need something that doesn't exist, you can build and publish your own skill to ClawHub.
